# Level 2 Project

Beginner web projects for the Summer Learning Challenge. Each folder is a browser-based project built without a framework.

## Project Folders

### WeatherApp

A browser-based weather dashboard for students, commuters, and travellers who want a fast, clean city weather view. Search for a city, see current conditions with an animated weather orb, check a 5-day forecast, and save favourite cities. It uses demo data; no live weather API is connected yet.

**What I learned:** DOM rendering without a framework, input validation, LocalStorage persistence, CSS animations, and responsive layouts.

**Tech Stack:** HTML5, CSS3, JavaScript (vanilla), LocalStorage

See [`WeatherApp/README.md`](WeatherApp/README.md) for full details.
