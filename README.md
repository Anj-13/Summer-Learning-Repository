# Summer Learning Repository

Everything I learn during summer holiday goes here. This repo captures all topics, projects, and experiments explored — regardless of the year. Browse the folders to see what's inside.

## Project Folders

### CouchToCoder2025

A full-stack web development journey through the Couch to Coder 2025 program. Starts from JavaScript basics and progresses to building a complete **Recipe Dashboard** — a full-stack app with CRUD API, dynamic frontend, and Chart.js data visualization.

**Sessions:**
- **Session 1** — JavaScript intro: variables, operators, control flow
- **Session 2** — Arrays, Objects, Loops
- **Session 3** — Node.js & Express.js server setup, GET/POST routes, JSON file I/O
- **Session 4** — HTML5 structure, CSS3 styling, DOM manipulation
- **Session 5** — Full CRUD API, async/await `fetch()`, HTML forms, CSS flexbox & media queries
- **Session Advanced** — Chart.js pie charts, data aggregation with `reduce()`
- **Combined** — Final integrated app: Recipe Dashboard + Cuisine Data chart with page navigation

**Tech Stack:** HTML5, CSS3, JavaScript (ES6+), Node.js, Express.js, Chart.js, JSON, CORS, npm

---

### docker-basic

A simple Node.js/Express.js app containerized with Docker for learning containerization fundamentals. Serves a "Test docker" message on port 9000.

**What I learned:** Dockerfile syntax (`FROM`, `WORKDIR`, `COPY`, `RUN`, `ENV`, `EXPOSE`, `CMD`), building images, running containers, port mapping, Docker vs local development workflows.

**Tech Stack:** Node.js, Express.js, Docker, Dockerfile

---

### Level 1 Project / Student Task Manager

A console-based task management application in Java for tracking student assignments, deadlines, and revision tasks. Features CRUD operations, file persistence, priority system (HIGH/MEDIUM/LOW), and input validation.

**What I learned:** Object-oriented design in Java (classes, enums, encapsulation), file I/O with `BufferedReader`/`BufferedWriter`, atomic file writes with `Files.move()`, `LocalDate` parsing, robust input handling with `Scanner`, and defensive programming (edge case handling, confirmation prompts).

**Tech Stack:** Java (8+), `java.time.LocalDate`, file I/O (`BufferedReader`/`BufferedWriter`, `Files.move()`)
